create

POST /logs

Operation ID: buildExportRequest.

Authentication: API key in the header (accessToken) or API key in the query (appId).

application/json

Property Type Required Description

Yes An array representing fields/columns available in your report. See Available EO Fields for the complete list.
filter array of string No A filter requires an array with 3 specific string values: ["Cthulu Prefix", "EO Field Key", "EO Field Value"]
limit integer (int32) Yes The maximum number of results to return.
report_type enum: eo_impression, eo_click, eo_branch_cta_view, eo_open, eo_install, eo_reinstall, ... Yes An array representing event type of your report. See Available Topics for the complete list.
response_format enum: csv, json No Format of returned data. json or csv
response_format_compression enum: gz, snappy No The file compression method to use for the data. Required if allow_multiple_files is set to true.
